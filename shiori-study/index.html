そのまま暗記ノートに。

使い方を見るデータの扱いについて →

いつもの教材から、復習へ。

追加する → 隠す → 思い出す

01 / IMPORT

自分の教材を取り込む

PDF・写真・テキストから教材を作成。対応するiPhone・iPadでは、カメラで書類をスキャンできます。

02 / HIDE

覚えたい部分を隠す

範囲をなぞってマーカーを作り、答えやヒントを保存。端末内の文字認識や、手書き・音声メモも使えます。

03 / REVIEW

自分に合う方法で復習

間隔をあけた復習に加え、カード・入力・選択・ペアの練習。学習記録と集中タイマーで、日々の積み重ねを確認できます。

教材は、手元で管理。

基本の学習に、アプリ用アカウントは不要。

教材と学習記録はアプリの端末内領域に保存します。開発者のクラウドへの自動同期や、外部AIによる教材処理は提供していません。現在の機能には広告・アプリ内購入もありません。

大切な教材は、別の場所にもバックアップを。
JSON・ZIPで書き出し、対応するしおり暗記の資料庫へ復元できます。端末内の世代バックアップや書き出しファイルは暗号化されていません。端末内にだけ保存したデータは、アプリの削除や端末紛失から保護できません。

把自己的教材，变成复习笔记。

しおり暗記面向 iPhone、iPad，支持 PDF、图片、文本导入，遮挡标注、间隔复习、翻卡、写答、单选、配对、手写和音频备忘。应用正在准备 App Store 正式发布，当前没有公开下载入口。

教材和学习记录保存在本地。当前没有开发者云同步、协作、远程 AI、广告或应用内购买。JSON / ZIP 及本地世代备份均未加密，请另行导出到安全位置；本地备份无法防止卸载或丢机导致的数据丢失。
